# idealista AI integrations

Official documentation for using idealista with supported AI assistants.

idealista integrations allow you to search real estate listings, retrieve
property details and access idealista help content directly from your
conversation.

## Available integrations

- [idealista for Claude](claude/)
- [idealista for ChatGPT](openai/)

These integrations are powered by idealista's MCP capabilities and are
available through the official directories of each platform.

## About this repository

This [repository](https://github.com/idealista/mcp-app-docs) contains user-facing documentation for the official idealista
AI integrations. It does not contain the source code of the idealista MCP
server.

## About idealista

[idealista](https://www.idealista.com/) is a real estate marketplace operating
in Spain, Italy and Portugal.
